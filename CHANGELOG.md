# Changelog

## 0.1.0 — technical preview

- Fail-closed Linux execution using bubblewrap namespaces and verified systemd user-service cgroup limits.
- Static byte triage, pinned Ghidra headless adapter, bounded metadata and selected decompilations.
- Input snapshots, explicit completion states, cleanup evidence, bounded diagnostics and portable consistency receipts.
- New-session retries with exact identity gates and comparison of exported function-name samples.
- Nine live boundary probes, adversarial receipt tests, optional real Ghidra equivalence tests and installed-package checks.

Initial support is deliberately narrow: a suitable unprivileged Linux host, Ghidra 12.1.4 and a full JDK 21 for the optional provider. No target execution, native fallback, arbitrary provider scripts, hosted service, or automatic specimen upload.
